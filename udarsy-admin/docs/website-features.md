# Udarsy Website — User-Facing Features

## Overview
Udarsy is Morocco's first AI-powered educational platform, designed for students from primary school through BAC.

---

## Core Features

### 🎓 Learning Hub
- **Full Moroccan Curriculum** — All subjects, all grades (1ère → Terminale), aligned with the national program.
- **AI Tutoring** — Personalized explanations, adaptive exercises, and instant feedback 24/7.
- **Past Papers & Mock Exams** — 1000+ BAC past-paper questions with AI-scored feedback.

### 🤖 AI Personalization
- Adaptive difficulty based on each student's performance history.
- Smart study schedules generated based on exam dates and learning pace.
- Instant explanations for any concept in Arabic, French, or English.

### 👥 Community
- **Study Groups** — Peer-to-peer collaboration spaces per subject and grade.
- **Teacher Q&A** — Verified teachers answer student questions in real time.
- **Achievements & Leaderboards** — Gamified progress to keep students motivated.

### 👨‍👩‍👧 Parent Dashboard
- Real-time progress reports and weekly summaries.
- Time-on-platform tracking and subject performance breakdown.
- Safe, monitored environment with content moderation.

### 📲 Accessibility
- Available on web and mobile (iOS & Android).
- Works on low-bandwidth connections.
- 100% free for students — no paywalls, no subscriptions.

---
