## 📸 The Master Image Prompt

```
You are generating a flat 2D digital graphic file — NOT a poster, NOT a mockup, NOT a photograph of printed material.

⚠️ OUTPUT FORMAT — ABSOLUTE PRIORITY:
- This is a RAW DIGITAL ARTWORK FILE. Treat it exactly like a .jpg export from Photoshop with no canvas border, no document shadow, no frame.
- The image IS the design. There is no "poster inside the image." There is no wall, table, paper edge, clip, tape, or room.
- Every pixel from corner to corner is part of the design itself. The design touches all four edges simultaneously.
- If any edge of the output shows a non-design element (shadow, margin, white space, frame line), the output is WRONG.
- Do NOT simulate depth, paper curl, or physical display of any kind.

⚠️ ABSOLUTE CONSTRAINTS:
- The ONLY text permitted in the image:
  1. "DARSY" — top-right corner, 5% margin from right and top, small clean modern sans-serif, no decoration
  2. Headline: "[INSERT HEADLINE]" — bold, large display type, positioned asymmetrically in the lower third or upper left. Use a clean geometric sans-serif. This must be legible and styled as editorial typography.
  3. Subline: "[INSERT SUBLINE]" — small, light weight, same sans-serif family, placed near the headline with clear hierarchy.
- Do NOT generate lorem ipsum, placeholder text, captions, watermarks, or any text NOT listed above.
- Do NOT add borders, frames, vignette glow, drop shadows, or margins at canvas edges.

🎨 COLOR PALETTE — zero deviations:
- Grayscale: all photographic/organic elements (figures, textures, skin, fabric)
- Accent green (#3aaa6a): ONLY on geometric elements — circles, arcs, rule lines, overlay fills, and text color for the headline
- Background: strictly [PURE WHITE #FFFFFF OR SOLID GREEN #3AAA6A]
- No warm tones, no blue, no yellow, no red — only grayscale + #3aaa6a

📷 FOREGROUND SUBJECT:
Topic: [INSERT TOPIC]
Scene: [INSERT CREATIVE SCENE DESCRIPTION]
The figure should be partially obscured by circular or ovoid geometric masks slicing through the body. Editorial fashion photography style: deep shadows, bright highlights, zero midtone softness.

📐 COMPOSITION:
- Asymmetric layout — subject MUST NOT be centered
- Minimum 2 overlapping geometric shapes (circles or partial arcs in #3aaa6a) layered across the figure
- At least one geometric element rotated 5°–30° off axis
- Depth via scale: one large shape + one small shape minimum
- Intentional negative space — do not saturate the canvas

✍️ TYPOGRAPHY PLACEMENT:
- Headline should feel like it belongs in the composition — not overlaid as an afterthought
- Let geometric shapes or figure elements partially overlap the headline text for editorial integration
- Headline weight: heavy/black. Tracking: tight. Color: #3aaa6a or pure white, whichever reads better against the background.
- Maintain clear hierarchy: DARSY (smallest) → subline (medium) → headline (largest)

🔧 MICRO DETAILS (decorative only, no labels):
- 1–2 thin rule lines in #3aaa6a, max 0.5% canvas width
- Small filled or hollow dot markers (< 0.8% canvas)
- Optional crosshair or grid tick in a corner — purely geometric

💡 LIGHTING:
- Hard directional from one side only
- Shadows: deep black. Highlights: clean white. No soft gradients on the figure.

❌ NEVER:
- Never center the main subject
- Never show the design inside a physical environment or frame
- Never use placeholder text of any kind
- Never add canvas borders or edge decorations
- Never soften contrast
- Never use opaque fills on geometric shapes — use strokes, partial fills, or transparent overlays
```
